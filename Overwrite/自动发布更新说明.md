# 自动发布策略更新

用户明确要求：跳过测试步骤。实施为跳过原生客户端实测，保留全部自动校验。

发布策略设为 automated_checks_only，原生验收 accepted 仍全部为 false。

本地 37 项自动测试通过，包括：
- 新增、修改、删除、删空及无效源文件拒绝发布。
- 上游版本变化、规范变化及网络失败阻止发布。
- 跳过客户端实测不豁免最新版本核查。
- 使用本地临时 Git 仓库验证四份固定输出在同一个提交中发布。
- 更新 main 后，旧任务不能覆盖新提交。

GitHub 上的首次自动发布尚未执行，需上传本包触发。线上运行与固定 URL 实际内容将在上传后核对。

本包不修改源文件、不直接替换四份覆写、不修改工作流路径。
